
# CueConnect757 — 757 Billiards Community Platform

## Overview

CueConnect757 is a community-driven platform serving the Hampton Roads billiards scene. It provides a single, neutral hub where players, teams, leagues, parents, and pool halls can connect, organize, and participate—regardless of league affiliation or skill level.


## Key Features

- Centralized league and tournament information (APA, BCA, USAPL, in-house)
- Unified tournament calendar and event discovery
- Team and player finder ("free agent" board)
- Youth program directory and parent tools
- Pool hall promotion and management


## User Roles

- **Player:** Create profiles, join teams, RSVP to events
- **Team Captain:** Manage rosters, schedules, and team openings
- **League Operator:** Manage leagues, seasons, divisions, and schedules
- **Pool Hall Owner:** Manage venue profiles, post tournaments, link leagues
- **Parent:** Manage youth profiles, RSVP for children, receive notifications
- **Admin:** Platform moderation and analytics

Users can hold multiple roles.


## Core Modules

- **League Directory:** All leagues, filterable and self-managed
- **Team Finder:** Teams post openings, players express interest
- **Player Finder:** Players mark themselves as "free agents"
- **Tournament Calendar:** Unified, filterable event calendar
- **Youth Programs Hub:** Directory and RSVP for junior programs
- **Pool Hall Profiles:** Venue details, amenities, linked events
- **Team & Youth Schedules:** RSVP and attendance tracking
- **Media/Streaming Hub:** Directory of live streams and VODs


## Data Model Highlights

- Users, Teams, Leagues, Pool Halls, Events, RSVPs, Player Skill Levels, Youth Profiles
- Modular design for easy expansion (e.g., points-based leagues, streaming)


## Architecture Principles

- Modular, role-based, neutral, mobile-first, scalable, and community-owned
